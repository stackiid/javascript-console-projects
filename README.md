## Overview

This repository is a collection of 5 console-based JavaScript projects, arranged from beginner to advanced. Each one was built to practice a specific set of concepts - starting with basic loops and conditionals and working up to multi-role applications with data relationships, algorithms, and admin dashboards.

It's intended for anyone reviewing practical JavaScript ability, and for other students who want to see how a set of small ideas (todo lists, inventory trackers, booking systems) grows in complexity as more language features come into play.

Every project lives in its own numbered folder with its own README explaining what it does and why.

## Repository Goals

This repository demonstrates:

- JavaScript fundamentals (variables, loops, conditionals, functions)
- Progressive learning, from single-file scripts to multi-role applications
- Working with arrays, objects, and arrays of objects as in-memory data models
- Input validation and error handling
- Console-based application and menu design
- Basic algorithmic thinking (discount logic, seat maps, recommendations)

## How to Use

1. Clone the repository.
2. Open any numbered project folder.
3. Read its `README.md` for what it does and the concepts it covers.
4. Copy `main.js` into your browser's developer console (F12 → Console) and press Enter to run it.
